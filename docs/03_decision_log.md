## 調査サマリ（参考: pato / ギャラ飲み業界）

### 運営・沿革

### 立て付け（重要）
- 運営は契約当事者にならず、キャスト⇄ゲスト間の「エンタメスキル提供契約」の成立機会を提供する
  **マッチング仲介**。〔pato 利用規約より / 確度: 高〕

### マッチング方式
- **パトコール**: 場所・時間・人数・クラスを指定し複数名を最短30分で呼ぶグループ型。
- **コパト**: 気になるキャストと1対1で日程調整する指名型。〔確度: 高〕

### 料金（pato 参考値）
- ポイント制。**1有償ポイント = 1.2円相当（税込）**、無償ポイント=1P=1円、消費は無償優先。
  （事前想定の「1P=1.1円」は税抜レートかまとめ記事の近似で、公式は1.2円）。〔確度: 高〕
- パトコール30分の目安: プレミアム4,250P、VIP7,000P、ロイヤルVIP12,500P。
  男性の利用目安 1時間 10,000〜30,000円/人。決済はクレジット/デビットカード。〔確度: 高〕
- おひねり: 5,000P〜。1人5,000〜10,000P目安。配分未指定なら均等分配。〔確度: 高〕
- ポイントは払戻し・換金不可、有効期限180日、退会で失効。〔確度: 高〕

### 審査
- 写真＋面談の二段階、通過率**約10%**とされるが**運営の自己公表値**（独立監査なし）。〔確度: 中〕
- 「登録キャスト15,000人突破/業界唯一の2段階面談」等の宣伝文言は検証で反証（鵜呑み不可）。

### 規模の数値
- 「累計会員40万人 / マッチング40〜60万回」等は**広報用の成長値で時点差・不一致あり**。
  事前想定の「18万人超」とは乖離。自社資料に転記しない。〔確度: 中〕

### 法規制の論点（詳細は 04_legal_compliance.md）
- 風営法: 「店舗から委託を受けて接客するものではない」→ 接客業務受託営業に非該当（運営主張）。
- 職安法: 「自由意思参加・指揮命令なし」論は**検証で反証（法的に安全と言い切れない）**。最重要リスク。
- 資金決済法: 有償ポイントは前払式支払手段に該当し得るが、**有効期限6ヶ月以内で適用除外**。
  基準日(3/末・9/末)の未使用残高1,000万円超で財務局へ届出義務。

## 意思決定（ADR: Architecture/Product Decision Records）

### ADR-001 対象エリアを岡山限定にする
- 決定日: 2026-08-12 / 状態: 採用
- 背景: マッチングは供給密度が命。地方で薄く広げると回らない。
- 決定: 岡山市中心部に絞り、供給先行で密度を作る。AREAS.serviceable で制御。

### ADR-002 MVP は patoコール（複数名）先行
- 決定日: 2026-08-12 / 状態: 採用
- 背景: 接待・二次会の高単価需要を先に取りに行く方針（ユーザー選好）。
- 決定: コパト（1対1）は次フェーズ。MVPはグループ呼び出しに集中。

### ADR-003 クライアントは Web（レスポンシブ / PWA）
- 決定日: 2026-08-12 / 状態: 採用
- 背景: アプリ審査を待たず最速で岡山市場を検証したい。
- 決定: Blade サーバレンダリング + PWA。ネイティブは後続。

### ADR-004 バックエンドは Laravel モノリス（コアサーバ）
- 決定日: 2026-08-12 / 状態: 採用
- 背景: 「コアサーバで動くもの」というユーザー方針。MVC純度が高く、認証・課金・管理画面が速い。
  capinfo の PHP 資産と相性。
- 決定: Laravel 11 モノリス。マイクロサービス化はしない。

### ADR-005 ポイントは台帳（イベントソーシング的）で管理
- 決定日: 2026-08-12 / 状態: 採用
- 背景: 前払式支払手段の監査可能性・二重計上防止。
- 決定: 残高カラムを持たず point_transactions の合算で残高算出。hold/capture/release/expire を型で表現。

### ADR-006 ポイント有効期限を180日（6ヶ月以内）に設定
- 決定日: 2026-08-12 / 状態: 採用
- 背景: 資金決済法の前払式支払手段の適用除外（6ヶ月以内）を取りにいく。
- 決定: 付与から180日で失効。※本番前に弁護士確認（04参照）。

### ADR-007 外部依存（決済PSP / eKYC / Push）は Adapter で抽象化
- 決定日: 2026-08-12 / 状態: 採用
- 背景: ベンダ未選定。テスト容易性と差し替え可能性。
- 決定: Contracts + Adapters。テストは Fake 実装。

---

### ADR-008 利用場所を制限する（密室禁止）
- 決定日: 2026-08-12 / 状態: 採用
- 背景: 安全確保・売買春回避・風営法/出会い系規制の観点。pato も同ルール。
- 決定: レストラン・バー・公共施設等のみ許可。鍵付き個室・ホテル・自宅・レンタルスペースを禁止。
  募集作成UI・規約・監視で担保（FR-P01b）。

### ADR-009 インターネット異性紹介事業として届出する
- 決定日: 2026-08-12 / 状態: 採用（手続き未）
- 背景: 男女がメッセージで会う約束をする仕組みは出会い系サイト規制法の対象。pato も届出済み。
- 決定: 事業開始前に岡山県公安委員会へ届出。児童利用禁止・誘引検知を実装。届出番号を表示。

### ADR-010 料金は地方pato準拠、テイクレートは前提値40%で開始
- 決定日: 2026-08-12 / 状態: 採用（テイクレートは前提＝要確定）
- 背景: 「初期パトをベンチマーク」。ゲスト料金は pato のエリア別表（岡山＝地方水準）を採用。
  ただしテイクレート実値は **pato 非開示**、2017年初期の料率カードも一次情報なし。
- 決定: ゲスト料金は地方水準【事実ベース】。**テイクレートは 40%（キャスト取り分60%）を作業
  デフォルト**とし、料金マスタ `take_rate_bp` の1設定で管理・上書き可能にする。初期は供給
  （キャスト）厚遇で岡山の密度を優先。詳細は `docs/06_pricing_model.md`。本番前に確定。
