## 1. 風営法（風俗営業等の規制及び業務の適正化等に関する法律）

- 論点: 「接待飲食営業」「接客業務受託営業」への該当性。
- 参考: 同種サービスは「飲食店舗から**委託を受けて**接客するものではない」ことを根拠に
  「接客業務受託営業」非該当と主張してきた（ただしグレーゾーンとの弁護士見解あり）。
- 設計上の担保:
  - [ ] 運営は店舗から接客を受託しない。店舗との間に接客委託契約を持たない。
  - [ ] キャストの行為は「会食・会話などのエンタメ」に限定し、接待該当行為を助長しない。
  - [ ] 岡山県／所轄警察の運用も確認（地域差がある）。
- **判断: 弁護士確認必須。** 建て付けだけで安全とはしない。

## 2. 職業安定法 / 労働法（最重要リスク）

- 論点: 労働者供給・有料職業紹介・偽装請負・労働者性。
- 注意: 「女性は自由意思で参加、指揮命令なし」という説明は、**それだけでは法的に安全と
  言い切れない**（本プロジェクトの事前検証でも否定的評価）。実態としての指揮命令性・
  専属性・報酬決定権が問われる。
- 設計上の担保:
  - [ ] 参加は完全に任意（募集への応募制。運営からの割当・強制・ノルマを作らない）。
  - [ ] キャストへの服務指示・時間拘束・ペナルティ設計を持たない（no_show の扱いは慎重に）。
  - [ ] 報酬はゲスト→キャストへの対価という建て付け。運営は仲介手数料を得る形を明確化。
  - [ ] キャストは個人事業主として自らスケジュール・受諾可否を決定できる。
  - [ ] 有料職業紹介に当たらないか（対価の性質）を精査。
- **判断: 弁護士確認必須。** ここが崩れると事業モデル全体に影響。

## 3. 資金決済法（前払式支払手段としてのポイント）

- 論点: 有償ポイントの前払式支払手段該当性・届出/登録・供託・有効期限。
- 整理:
  - [ ] 有償ポイントは前払式支払手段に該当し得る。**有効期限を6ヶ月以内（=180日）**に
        設定すれば、前払式支払手段に関する規定の**適用除外**を受けられる（施行令）。
        → 本サービスは有効期限180日を採用（ADR-006）。
  - [ ] 適用除外は「前払式支払手段の章」に関するものであり、法全体の免除ではない点に注意。
  - [ ] 万一 6ヶ月超の設計に変える場合は、**基準日（3月末・9月末）の未使用残高が
        1,000万円超**で財務局への届出義務等が発生。残高モニタリングを実装できる状態にする。
  - [ ] 「未使用残高の半額以上を2ヶ月以内に供託」等の理解は誤りに注意（供託は登録/届出発行者の
        制度で、6ヶ月以内失効の適用除外なら原則対象外）。要弁護士確認。
- 実装:
  - [ ] ポイント台帳で未使用残高を常時集計可能に（NFR-06）。
  - [ ] 有効期限・失効を規約とUIに明示。払戻し/換金不可を明示。
