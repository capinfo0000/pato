## 「pato に準拠する」で足りるもの / 足りないもの

pato（株式会社キネカ）を参考にする場合、**準拠できる範囲を正しく分けること**。

### ✅ 準拠できる（設計・表示・運用ルール）— 実装済み

| 論点 | pato の建て付け | 本サービスの実装 |
|---|---|---|
| サービスの位置づけ | 運営は契約当事者にならない仲介 | 利用規約 第1条に明記 |
| 利用場所 | 密室（ホテル・自宅・鍵付き個室）禁止 | 規約 第3/4条＋`venue_kind` を公共の場に限定 |
| 年齢確認 | 本人確認書類で18歳以上を確認 | eKYC 必須。未確認・未成年は作成/参加不可 |
| ポイント | 払戻し・換金不可、有効期限180日 | 台帳の `expires_on`、規約 第5条、特商法表記 |
| 表示 | 特商法表記・規約・プライバシーポリシー | `/commerce` `/terms` `/privacy` |
| 安全 | 24時間監視・通報・SOS | 通報／制裁／SOS／NG検知を実装 |

### ❌ 準拠できない（事業者ごとに必要）

| 項目 | 理由 |
|---|---|
| **インターネット異性紹介事業の届出** | **事業者ごとの届出**。pato の登録番号（麻布20-073700）は株式会社キネカが東京都公安委員会へ届け出たもので、他社は使用できない。無届での営業は罰則対象 |
| **弁護士レビュー** | pato の顧問弁護士は pato のサービスを見たのであって、本サービスを見たわけではない。実装・運用の差分は自社で確認が必要 |
| 特商法表記の事業者情報 | 自社の商号・所在地・責任者を記載する |

## 1. インターネット異性紹介事業の届出（必須・人の手続き）

**根拠**: 出会い系サイト規制法。男女が面識のない相手とメッセージで会う約束ができる仕組みは
「インターネット異性紹介事業」に該当し得る。

**いつ・どこへ**
- **事業開始日の前日まで**に届出
- **事業の本拠となる事務所の所在地**を管轄する**警察署（生活安全課）を経由**して**岡山県公安委員会**へ

**届け出る内容（例）**
- 氏名・住所（法人は商号・所在地）
- 事業を示す呼称（サービス名）
- 事務所の所在地・連絡先
- ウェブサイトの URL
- **児童でないことの確認の実施方法**（本サービスは eKYC による年齢確認）

**添付書類（法人の場合の例）**
- [ ] 事業開始届出書
- [ ] 定款
- [ ] 登記事項証明書
- [ ] 役員に関する書面（住民票の写し等。所轄で要確認）

**運用**
- [ ] 取得した登録番号を `PATO_IDS_REGISTRATION` に設定 → フッターに自動表示
- [ ] 届出事項の変更時・事業廃止時も届出が必要
- [ ] 児童の利用禁止と、児童を性交等に誘引する書き込みの**検知・削除**体制（`ContentFilter`＋通報対応）

---

## 2. 弁護士レビュー（必須・人の手続き）

`docs/04_legal_compliance.md` の各論点を、**本サービスの実装・運用を見せた上で**確認する。

- [ ] 出会い系サイト規制法（届出内容・年齢確認方法の妥当性）
- [ ] 風営法（接客業務受託営業への非該当性。岡山県警の運用も確認）
- [ ] **職業安定法 / 労働法（最重要）** — キャストの労働者性・指揮命令性。
      「自由意思で参加」だけでは安全と言い切れないため、規約・運用・報酬フローを実物で確認する
- [ ] 資金決済法（有効期限180日による適用除外の妥当性）
- [ ] 個人情報保護法（eKYC 結果・生年月日の取扱い、保持期間）
- [ ] 特商法（定期購入を導入する場合は自動更新の表示）
- [ ] 利用規約・プライバシーポリシー・キャスト規約の文言（本リポジトリのものは**雛形**）

## 3. コードで確認できる条件（`pato:release-check`）

| チェック | 内容 |
|---|---|
| 特商法表記の事業者情報 | 商号・責任者・所在地・連絡先が設定済み |
| 届出番号 | `PATO_IDS_REGISTRATION` が設定済み |
| 法定表示ページ | `/terms` `/privacy` `/commerce` が存在 |
| ポイント有効期限 | 180日以内（資金決済法の適用除外） |
| 払戻し不可 | 設定が `false` |
| 利用場所 | 密室が許可されていない |
| 年齢 | 18歳以上 |
| 外部アダプタ | 決済・eKYC・Push が Fake でない（本番のみ致命） |

**設定例（`.env`）**

```dotenv
PATO_OPERATOR_NAME="株式会社◯◯"
PATO_OPERATOR_REP="山田 太郎"
PATO_OPERATOR_ADDRESS="岡山県岡山市北区◯◯1-2-3"
PATO_CONTACT_EMAIL="support@example.com"
PATO_CONTACT_PHONE="086-000-0000"
PATO_IDS_REGISTRATION=""   # 届出後に取得した番号を設定（他社の番号は使用不可）
```
